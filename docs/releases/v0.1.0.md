Shell Buddy turns a leading `//` description into a shell command, with local rules, accepted-command cache and a selected streaming model.

This first release includes macOS Apple Silicon/Intel, Linux x86_64 and Windows x86_64 bundles. Each bundle includes the custom lizard icon font and a current-user installer. Icons default to the standard star; the custom font is opt-in after terminal font setup. `init` configures the application and never downloads fonts.

Downloads include SHA-256 checksums. Extract the complete archive and run its installer. See the bundled README and font guides for shell initialization, credentials and font configuration.

Model and network latency depend on the configured provider. Terminal-specific modified Enter requires key configuration. Font installation alone does not select the terminal rendering font. The binary is not yet signed or notarized.
