Shell Buddy v0.2.0 makes AI input feel like part of your shell: one gold prompt, a quiet input background, and clear generation and acceptance states.

### What changed

- AI mode temporarily takes over the current input row with a single gold `❯`. Your original `$`, `%`, `>`, or themed prompt returns when you accept or cancel; context above a multiline prompt stays visible.
- Empty input displays `What do you need?`. Generation and Tab refresh change prompt brightness, while complete commands reveal an acceptance hint. Partial or hidden commands remain unavailable for acceptance and execution.
- The default `input_style: "square"` needs no custom font. Optional `input_style: "rounded"` uses the included **Shell Buddy Icons 1.1** font, with single-line and multiline corners.
- Background painting handles pane resizes without wrapping old-width padding into extra rows. Chinese editing, candidate wrapping, and native prompt restoration have additional regression coverage.
- The font patcher adds the new cap glyphs to a fresh copy of your static monospace font while preserving its original text glyphs and advances. It rejects occupied private-use slots and existing output files.

### Upgrade

Install the matching bundle, then reload the integration in existing sessions:

```sh
# Zsh
eval "$(shell-buddy init zsh)"
# Bash 5+
eval "$(shell-buddy init bash)"
```

```powershell
shell-buddy init powershell | Out-String | Invoke-Expression
```

Model profiles and credentials are preserved. Legacy `icon` and `nerd_font` settings are ignored; missing `input_style` defaults to `square`. The setup wizard removes those legacy fields when saving.

To enable rounded input, first configure **Shell Buddy Icons 1.1+** in your terminal, then choose `rounded` in `shell-buddy init` or set `"input_style": "rounded"` in your existing configuration and run `shell-buddy restart`. Existing mascot-only fonts and patched text fonts must be updated. Installing the symbol font does not automatically select it in your terminal. See the bundled font guides for mapping and patching instructions.

### Downloads

Bundles include the executable, symbol font, and current-user installer for macOS Apple Silicon, macOS Intel, Linux x86_64 (musl), and Windows x86_64. Verify downloads with the attached `SHA256SUMS`.

Release packages are built and checked on native macOS, Ubuntu, and Windows runners. Model tests use offline mock services; font rendering still depends on terminal configuration. Binaries are unsigned and macOS builds are not notarized.
