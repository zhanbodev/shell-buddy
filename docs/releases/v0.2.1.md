Shell Buddy v0.2.1 polishes the AI input experience with a particle reveal, a compact loading spinner, and steadier text and cursor rendering.

### What changed

- Entering `//` reveals the input background from left to right over 720ms. Gold particles follow the moving front and disappear when the plain background is fully open. Typing, pasting, or resizing immediately completes the animation.
- Model generation uses an npm-style dot spinner in the prompt position. It needs no Nerd Font and returns to the arrow when the request completes, fails, or is cancelled.
- Spinner ticks update only the icon cell. Descriptions and streamed command prefixes stay in place instead of being cleared and redrawn. Entry particles avoid the placeholder, and cursor movement is hidden during painting to prevent visible jitter.
- Tab keeps its clear-and-refresh feedback while preserving incomplete-command protection, candidate deduplication, and request cancellation.
- Added `shell-buddy update`, `update --check`, and `update --no-font`, with shell completion. Updates verify SHA-256 checksums and preserve model configuration, credentials, and cache.
- Added the MIT license to the repository and release bundles. Copyright belongs to Liang Zhanbo (梁展波), founder of Nuclx Tech, in a personal capacity.

### Upgrade

For v0.2.0 and earlier, run the installer once:

```sh
curl -fsSL https://raw.githubusercontent.com/zhanbodev/shell-buddy/v0.2.1/install.sh | sh -s -- --version v0.2.1
```

```powershell
$installer = Join-Path $env:TEMP 'shell-buddy-install.ps1'
Invoke-WebRequest https://raw.githubusercontent.com/zhanbodev/shell-buddy/v0.2.1/install.ps1 -OutFile $installer
pwsh -File $installer -Version v0.2.1
```

Reload the integration in existing sessions:

```sh
# Zsh
eval "$(shell-buddy init zsh)"
# Bash 5+
eval "$(shell-buddy init bash)"
```

```powershell
shell-buddy init powershell | Out-String | Invoke-Expression
```

Future releases can be installed with `shell-buddy update`. The default square background and loading spinner need no custom font. Rounded input continues to use Shell Buddy Icons 1.1; no new font glyphs are required for this update.

### Downloads

Bundles include the executable, symbol font, MIT license, and current-user installer for macOS Apple Silicon, macOS Intel, Linux x86_64 (musl), and Windows x86_64. Verify downloads with the attached `SHA256SUMS`.

Release packages are built and tested on native macOS, Ubuntu, and Windows runners. Model tests use local mock services. Binaries are unsigned and macOS builds are not notarized.
